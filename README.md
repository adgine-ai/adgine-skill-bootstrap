# Adgine Skill Bootstrap (production)

This branch contains the generated `production` Bootstrap Skill for compatible Agent hosts. Install it from `https://github.com/adgine-ai/adgine-skill-bootstrap`, configure only a new `adg_sk_live_*` Adgine API Key for the same environment, and synchronize the Skills authorized for that Key. It connects only to `https://access-center.adgine.ai`; the target Skills directory is detected from the Bootstrap installation location.

The source of truth lives in the private `adgine-skills` repository. Files in this distribution repository are generated by its release process and should not be edited independently.

## Install and synchronize

1. Use the release ZIP generated by `adgine-skills/scripts/publish-bootstrap.py`; it has `SKILL.md` at the archive root.
2. Install the ZIP in the target Agent.
3. Configure only `ADGINE_API_KEY` in the Agent's secret/environment settings.
4. Ask the Agent to check, synchronize, update, or refresh Adgine Skills; all four requests immediately apply the current server Manifest.
5. If the synchronized Skills are not visible immediately, refresh or restart the Agent once.

The authenticated Manifest supplies the runtime service endpoints. Bootstrap rejects an environment mismatch and child Skills do not silently fall back from test to production.

Legacy `geo_sk_live_*` and `abi_*` Keys remain supported by their original product authentication paths. They are intentionally not accepted here. The earlier POC `agk_*` format is also unsupported.

Each Agent's native dynamic discovery behavior is an explicit compatibility decision gate; it is not assumed to be guaranteed by the Bootstrap.

The Bootstrap checks its installed `VERSION` against GitHub and prompts when a newer release ZIP is available. Child Skills call the cached preflight path, which refreshes the Access Center Manifest at most once per 10-minute activity window. Explicit synchronization and recognized permission-denied responses force an immediate refresh.
